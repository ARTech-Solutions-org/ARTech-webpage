## Layout requirements

### Desktop / laptop (≥1024px)
Recreate a **landscape, multi-column layout**:
- Top bar: name/title on the left, Education + contact info on the right
- Below that, four columns side by side:
  1. Creative DNA card + Portfolio card stacked
  2. Centered portrait photo with the squiggle arrow accent
  3. Skills list + Mega Clients card stacked
  4. Creative Journey card (tall, scrollable list of roles)
- Cards should have subtle hover states (slight lift/shadow) since this is a portfolio site, not a static PDF

### Mobile (≤767px) and tablet in between
Recreate a **single-column, portrait/stacked layout** in this order:
1. Name + title
2. Portrait photo
3. Education + contact info
4. Creative DNA card
5. Portfolio card
6. Skills list
7. Mega Clients card
8. Creative Journey card (full list)
- Reduce the giant wordmark font size proportionally so it never overflows the viewport width or wraps awkwardly
- Make sure all cards go full-width with comfortable padding, text stays readable (min ~15px body text), and tap targets (the Behance link, contact links) are large enough for touch

### General responsive behavior
- Use CSS `clamp()` or media queries for fluid type scaling of the big wordmark and headings
- Test/handle the breakpoint range between mobile and desktop (tablet, ~768–1023px) with a sensible intermediate layout (e.g., 2 columns) rather than jumping straight from 1 to 4 columns
- Make the email and phone number clickable (`mailto:` and `tel:` links)
- Add smooth scroll and a simple fade/slide-in animation on scroll for each section (nice-to-have, keep it subtle and performant)
- Ensure good color contrast for accessibility (white/light grey text on the dark background already helps, just double check the muted grey wordmark and grey timestamps aren't too low-contrast against the background)
- Add a `<title>` and meta description for SEO: "Mohamed Rady — Senior Art Director"
- Keep the whole thing to a single scrolling page (no routing needed)
